# 金蝶云星空【销售订单】字段批量修改插件
### 1、需求场景：在单据列表勾选多条单据行明细信息，并对其中字段进行修改。金蝶云星空BOS平台可配置的【批改功能】只对属性为【基础资料】的字段生效，若需要对一些非【基础资料】或自定义字段进行批量修改，则需要插件来实现该功能。
### 2、准备工作：①搭建动态表单，用于动态获取在列表勾选的行明细信息中需要修改的字段信息，如单据编号、单据行号、需批改字段等，建议再加上单据头的FID及单据明细的FentryId，以便后续通过FID和FentryId对数据进行修改，同时将单据体标识改为“F_SCS_Entity”。
###              ②在销售订单列表增加一个按钮，并将其标识改为“SCS_Button_BatchModify”，用于呼出动态表单。
###              ③在动态表单上新增按钮：修改，并将其标识改为“SCS_MODIFY_DY_DATA”，用于获取用户维护在动态表单的明细信息，以便后续在数据库中更新。
### 3、基本原理：①通过按钮事件，触发读取列表行信息，并将每条明细的FID和FentryId分别存储在fidList和fentryIdList中。
###              ②解析获取到的fidList和fentryIdList，并通过FID和FentryId在数据库中查找相应的字段信息，遍历后展示在动态表单中。
###              ③用户在动态表单维护好需要修改的数据后，再次通过按钮事件，遍历获取动态表单行明细的字段信息并动态生成更新SQL用于执行。根据返回的执行结果数判断更新是否成功。
### 4、备注：实际逻辑可根据业务场景自行修改。
## 2028-05-01 修改批改插件逻辑：允许FDATE和FREASON不同时为空。
## 2025-05-01 【新增】 销售订单保存校验服务插件：当【销售订单】明细行【客户物料编码】不为空时，若【库存组织】与【销售组织】不一致，则根据【物料编码】、【客户物料编码】、【客户ID】及【库存组织ID】在【客户物料对应表】中查询分发信息，若查询结果为0，则抛出异常并提示所有未查询到的行。
